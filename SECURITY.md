# Política de seguridad

## Versiones compatibles

Durante la fase inicial solo se mantiene la versión publicada más reciente.

## Notificación responsable

No publique vulnerabilidades, API keys, datos personales o evidencias sensibles en un issue público. Use el reporte privado de seguridad de GitHub si está habilitado. Si no existe, solicite al mantenedor un canal privado sin revelar detalles explotables.

Incluya versión y navegador, impacto, reproducción con datos sintéticos, componentes afectados y mitigación sugerida.

Son prioritarios los fallos que puedan exponer investigaciones, conservar secretos sin redactar, ampliar la captura a pestañas no seleccionadas, ejecutar código remoto o permitir una manipulación no detectable de la evidencia.

No realice pruebas destructivas ni sobre sistemas de terceros sin autorización.

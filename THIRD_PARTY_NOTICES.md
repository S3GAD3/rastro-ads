# Avisos de terceros

RASTRO-ADS 0.7.0 no incorpora librerías JavaScript, SDK ni código de ejecución de terceros.

La herramienta es interoperable con formatos y servicios externos, entre ellos:

- ads.txt, app-ads.txt y sellers.json, especificaciones promovidas por IAB Tech Lab;
- Google AdSense, Google Ad Manager, Google Analytics, Google Tag Manager y Google Search Console;
- Meta Pixel;
- TikTok Pixel;
- Microsoft Advertising UET;
- VirusTotal.

Las marcas pertenecen a sus respectivos titulares. Su mención es descriptiva y no implica patrocinio, afiliación, certificación o aprobación.

Google, Meta, TikTok, Microsoft, IAB Tech Lab y VirusTotal no patrocinan, certifican ni mantienen RASTRO-ADS.

Los datos consultados desde `ads.txt`, `app-ads.txt`, `sellers.json` y las API externas no se relicencian bajo MIT. Su acceso y reutilización quedan sujetos a los términos del proveedor y a la normativa aplicable.

La licencia MIT incluida en este repositorio se aplica únicamente al código y documentación originales de RASTRO-ADS sobre los que S3GAD3 ostente derechos.

La API pública gratuita de VirusTotal está sujeta a límites y restricciones de uso, incluidas restricciones para productos comerciales y determinados flujos profesionales. El usuario es responsable de disponer de una modalidad compatible y cumplir sus términos.
